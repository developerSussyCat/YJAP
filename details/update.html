Changes to YJAP

An update about the name and information in the archive.

Major Updates · November 2, 2026

Update details

← Back to the archive

Details

Shortly after publishing the archives, we realized the name YJAP wasn’t quite right. The archive is mainly intended for ninth graders, so we decided to change the name.

The archive is now called the YFA, which stands for YGW Freshies Archives. The new name better fits who the site is for and what it collects.

We also reviewed the other posts and corrected information that wasn’t accurate. In recent updates about Peak Portfolio, we discovered issues with misspelled names and inaccurate information.

Other things we updated

  • Clickable content for some posts that will bring you to additional pages.
  • We are now open-sourced; you can view the code at the GitHub repository .
  • If you see an error or would like to make a correction, go to “Issues” in the GitHub repository and create a new issue.

We’ll continue adding new posts and updates as the school year goes on. Check back regularly for the latest highlights from around YGW.

The YGW Junior Archives, or YFA, is an archive of noteworthy happenings and memorable moments from around YGW.
